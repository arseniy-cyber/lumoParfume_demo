# Lumo Parfum v12 — фирменный знак, редакционные фото, анимация

## Готово

- Восстановлена оригинальная фотография с чёрным Toskovat справа в композиции «Каждая история имеет свой шлейф» — взята из v10 без перерисовки и без накладок поверх фото. Главная композиция также восстановлена из исходника.
- Создан полноценный фирменный медальон с монограммой LP + словесная часть Lumo Parfum (PNG с прозрачным фоном): `assets/lumo-logo-light.png`, `assets/lumo-logo-dark.png` и `assets/lumo-monogram.png`.
- PNG-логотип установлен в шапку, меню, подвал и на коричневый экран переходов. Флакон текущего бренда остаётся рядом с логотипом и выбирается по адресу перехода.
- Сюжеты фотографий разведены по разделам: кожаная туфля и цветы, тёплые янтарные композиции, скульптура, дым благовоний, камень и ткань. Главная сохраняет согласованную композицию.
- В выборочных заголовках используются антиквенные и рукописные акценты, в том числе красно-бордовый почерк. Декоративные шрифты при наличии интернета загружаются из Google Fonts, иначе применяются системные альтернативы. Файлы шрифтов в комплект не включены.
- Появления заголовков теперь раскрываются как строка, фотографии плавно разрешаются из небольшой глубины; уменьшена резкость событий колесика, при `prefers-reduced-motion` анимации отключаются.
- Сглажены 1-пиксельные дефекты альфа-маски у трёх выбранных чёрных флаконов Tom Ford, без замены самих фотографий на сгенерированные.
- Сохранены 102 товара и 306 локальных PNG из пользовательского архива. Сохранена работа избранного, корзины и подбора по нотам.

## Как запускать

Распакуйте весь ZIP, затем откройте `index.html`. Для корректного тестирования локального хранилища и переходов можно запустить папку через VS Code Live Server или `python -m http.server 8000`.

## Проверки

Синтаксис JavaScript проверен для пяти скриптов. Файлы 102 товаров и все 306 PNG с прозрачным альфа-каналом присутствуют. Сверено, что оригинальная сцена с Toskovat совпадает побайтно с исходным v10. Интерфейс проверен в Chromium через встроенный тест HTML/CSS/JS для главной (desktop/mobile), каталога и страницы «О проекте»: без ошибок JavaScript и горизонтальной прокрутки. Прямые переходы между `file://` HTML-страницами в браузере тестовой среды заблокированы.

**Демонстрационный сайт**: настоящая оплата и оформление заказов отсутствуют. Окончательное качество всех 306 ручных вырезок должно оцениваться по оригинальным файлам: автоматическая проверка прозрачности не заменяет визуальную проверку каждого края.


## Версия 13 — типографика, логотип, фото и мобильная версия
- Новый знак LP — самостоятельная переплетённая монограмма без кружка. Отдельные PNG в assets/lumo-mark-lp.png и assets/lumo-logo-light.png, assets/lumo-logo-dark.png.
- 306 исходных PNG соответствуют 102 ароматам. Вторая фотография Nasomatto Black Afgano исправлена использованием третьего оригинального кадра того же флакона, без подмены бренда.
- Фон «Каждая история имеет свой шлейф» имеет только прозрачный Toskovat Anarchist справа (чёрного флакона позади нет). Исходная утверждённая композиция сохранена: задний чёрный флакон удалён, а передний прозрачный Anarchist восстановлен из оригинала без изменений остальных флаконов.
- Заголовки больше не используют обрезающую CSS clip-path маску; секции допускают полный текст при переносах.
- Винтажные и рукописные шрифты подключаются из Google Fonts при наличии интернета; есть встроенные системные замены.
- Шрифт Los Angeles Homies по данным владельца доступен в демоверсии только для некоммерческого использования, поэтому он не встроен и не передаётся: для аналогичного декоративного эффекта применены другие шрифты. Для коммерческого использования оригинала потребуется лицензия.
- Вся навигация, поиск, список избранного, корзина и подбор по нотам сохранены.
